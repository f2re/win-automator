# Employee entry example

Минимальный пример переноса строк Excel в тестовую WinForms-форму Win Automator.

1. Из корня репозитория запустите `scripts\TargetForm.ps1`.
2. В Win Automator откройте `sample-data.xlsx`, лист `Employees`.
3. Запишите первую строку в режиме обучения.
4. Нажмите `F9`.
5. Проверьте шаги и выполните тест на второй строке.
6. `scenario.json` показывает ожидаемую структуру смыслового сценария; реальные identifiers могут немного отличаться в зависимости от того, как UIA видит форму на конкретной системе.
